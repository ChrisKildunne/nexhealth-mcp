## NexHealth Sandbox Setup — Overview

Welcome! This guide walks you through everything needed to go from a brand new
developer account to booking your first test appointment through the NexHealth API.

The sandbox environment is pre-populated with test data so you can verify your
integration without needing a PMS or EHR set up. No real patients or practices
are affected.

Steps:
  1. dev_portal         — Create your developer account and get your sandbox API key
  2. api_key            — Store your API key securely so the MCP server can use it
  3. sandbox_first_call — Make your first test API call and verify end-to-end

step by step.
