## Step 2b — Install Open Dental (Test EHR)

Perform ALL of these steps inside Windows — inside Parallels if you are on a Mac.

1. Download the Open Dental installer:
   https://opendental.com/TrialDownload-25-3-48.exe

2. Run the installer and grant any requested permissions.

3. When you reach the configuration settings page, ignore all settings
   and click "Install".

4. On the popup that appears, click "Next" through the setup wizard
   until you reach the Install page, then click "Install".

5. Click "Finish" when the installation completes.

6. When the "MySQL Credentials" popup appears, enter a password of your
   choice and click "OK". Save this password — you will need it later.

7. Click "OK" again, then close the original installer window.

8. In the Windows search bar, search for "Open Dental" and select
   "Run as administrator".

9. Click "Yes" on the permissions prompt.

10. Enter the MySQL password you created in step 6, then click "OK".

You now have a fully operational Open Dental demo instance that mirrors
what a real dental practice would use.
